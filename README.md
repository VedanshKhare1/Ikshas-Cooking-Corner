# 🍳 Iksha Cooking Website

A modern and responsive cooking website built to showcase **Iksha Cooking's** YouTube content, recipes, and contact information in one place.

## 🌐 Live Website

🔗 https://vedanshkhare1.github.io/Website/

## ✨ Features

- 🎥 Automatically displays the latest YouTube videos
- 📺 Featured cooking videos section
- 📖 Free downloadable Recipe Book (PDF)
- 📩 Working Contact Us form (EmailJS)
- 📱 Fully responsive design
- ⚡ Fast loading and clean UI
- 🎨 Modern cooking-themed interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Node.js
- Express.js
- YouTube Data API v3
- EmailJS
- GitHub Pages
- Render

## 🚀 How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/VedanshKhare1/Website.git
```

2. Install dependencies

```bash
npm install
```

3. Create a `.env` file

```
YOUTUBE_API_KEY=YOUR_API_KEY
```

4. Start the backend

```bash
node server.js
```

5. Open `index.html` in your browser.
